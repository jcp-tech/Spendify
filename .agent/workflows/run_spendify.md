---
description: Start all Spendify services (ADK, API, Bot)
---

1. Start the ADK Pipeline Server

   - Command: `adk web`
   - Directory: `adk_pipeline`
     // turbo

2. Start the Flask API

   - Command: `python main_api.py`
   - Directory: `flask_api`
     // turbo

3. Start the Discord Bot
   - Command: `python bot.py`
   - Directory: `discord_bot`
     // turbo
